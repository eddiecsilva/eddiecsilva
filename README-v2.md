## Projetos

Alguns dos projetos e experimentos disponíveis aqui:

### 🐧 Debian Post Install

Scripts e configurações para automatizar a preparação de um ambiente Debian voltado para produtividade, criação de conteúdo, jogos e uso cotidiano.

### 🖥️ Plasma Productivity Menus

Service Menus para o KDE Plasma/Dolphin com foco em produtividade e automação de tarefas diretamente pelo gerenciador de arquivos.

### 🤖 Local AI & Homelab

Experimentos com modelos de linguagem locais, servidores de inferência, automação, RAG e ferramentas para integrar IA ao fluxo de trabalho.

> A maioria desses projetos nasce de uma necessidade real. O objetivo é testar, documentar e compartilhar soluções que possam ser úteis para outras pessoas.
